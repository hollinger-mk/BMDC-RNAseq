# BMDC-RNAseq
Documentation for RNA-seq analysis of EPS-treated BMDCs

This experiment was performed by Rishi Sureshkumar in the Sperling lab in 2024.
BMDCs were generated from C57BL/6J (wt) or TLR4-lps-del (ko) mice using Flt3L and GM-CSF. Cells were then plated at 8e5 cells/ml in 10% DMEM. 4e5 cells were plated in a 24 well plate, and EPS was added at 1 ug/ml. After 24 hours with EPS, some wells were treated with OVA for 2.5 hours. Then, all BMDCs were harvested and RNA isolated. 

RNA was isolated using Zymogen kits and sequenced at NovoGene. 

Four groups were sequenced with the following codes:
A: PBS 
B: EPS (24h)
C: OVA (2.5h)
D: EPS (24h) + OVA (2.5h)
